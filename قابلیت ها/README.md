# فهرست قابلیت‌های محصول (Product Backlog)

**P0 = نسخه اولیه ضروری؛ P1 = پس از پایلوت؛ P2 = پیشرفته.** تمامی اولویت‌ها پیشنهادی‌اند.

## خریدار
| اولویت | قابلیت | معیار پذیرش نمونه |
|---|---|---|
| P0 | ثبت‌نام/ورود با موبایل | OTP محدودشده و امن |
| P0 | دسته‌بندی و فیلتر وزن/عیار/قیمت/مناسبت | فیلتر مطابق داده واقعی کالا |
| P0 | صفحه محصول با تصویر و مشخصات کامل | وزن، عیار، اجرت، سود، مالیات و شرایط تحویل مشخص |
| P0 | پروفایل فروشنده | وضعیت احراز و اطلاعات مجاز برای نمایش |
| P0 | قیمت نهایی معتبر + پرداخت مجاز | عدم تغییر مخفیانه قیمت پس از تأیید |
| P0 | مشاهده وضعیت سفارش و درخواست پشتیبانی | تاریخچه وضعیت شفاف |
| P1 | لیست علاقه‌مندی، مقایسه محصولات، اعلان | قابل خاموش‌کردن |
| P2 | جست‌وجوی تصویری، پیشنهاد هوشمند و AR | با آزمون UX و حفظ حریم خصوصی |

| P1 | ویترین اختصاصی و اشتراک | قوانین قیمت‌گذاری شفاف |

## مدیر پلتفرم
| اولویت | قابلیت | معیار پذیرش نمونه |
|---|---|---|
| P0 | تأیید/تعلیق فروشنده و کالا | چرایی و عامل اقدام ثبت شود |
| P0 | موتور نرخ/قیمت و تنظیمات مالیاتی | نسخه‌بندی و audit trail |
| P0 | مدیریت سفارش، اختلاف، بازپرداخت | دسترسی نقش‌محور |
| P0 | گزارش تراکنش و تطبیق تسویه | هیچ پرداخت یا تسویه بدون شناسه یکتا نباشد |
| P0 | لاگ، امنیت، بکاپ، مانیتورینگ | تست بازیابی مستند |

## غیرقابل مذاکره
- نرخ، مبلغ نهایی، مالیات و وضعیت موجودی **سمت سرور** محاسبه و تأیید شوند.
- کلیدهای پرداخت، مدارک شناسایی و اطلاعات خصوصی در Git قرار نگیرند.
- همه عملیات حساس idempotent، دارای ثبت تغییرات و قابل پیگیری باشند.
- دسترسی به مدارک فروشندگان با اصل حداقل دسترسی و نگهداری محدود باشد.
