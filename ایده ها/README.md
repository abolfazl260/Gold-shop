# بانک ایده‌ها

ایده‌ها در این صفحه «پیشنهاد» هستند، نه فیچرهای تصویب‌شده. معیار اولویت: اثر بر اعتماد/تبدیل، هزینه ساخت، ریسک مقرراتی، شواهد نیاز مشتری.

| ایده | مشکل حل‌شده | فاز پیشنهادی | وضعیت |
|---|---|---|---|
| مقایسه اجزای قیمت چند فروشنده | ناتوانی در مقایسه قیمت واقعی | ۱ یا ۲ پس از بررسی UX | نیازمند اعتبارسنجی |
| پروفایل فروشنده احرازشده | نگرانی درباره اعتبار و اصل بودن طلا | MVP | پیشنهادی |
| خرید بر اساس بودجه و مناسبت | دشواری انتخاب هدیه | MVP | پیشنهادی |
| کالاهای سبک و کم‌اجرت | محدودیت بودجه مشتری | MVP (دسته‌بندی) | پیشنهادی |
| جست‌وجوی محصول با عکس | مشتری تصویر مرجع دارد | فاز ۳ | ایده |
| سفارش ساخت اختصاصی | محصول دلخواه موجود نیست | فاز ۲ | ایده |
| محتوای ویدئویی از اندازه واقعی محصول | عدم درک ابعاد و ظاهر | فاز ۲ | ایده |
| هشدار موجودشدن محصول/تغییر قیمت | تصمیم خرید به زمان حساس است | فاز ۲ | ایده |
| پیشنهاد هوشمند برای هدیه | انتخاب مدل بر اساس مخاطب/بودجه | فاز ۳ | ایده |
| ابزار ساخت ویترین گالری | دشواری دیجیتالی‌شدن فروشندگان | فاز ۲ | ایده |

## ارزش پیشنهادی اولیه
«دسترسی به مجموعه‌ای از طلافروشی‌های معتبر، با امکان مقایسه منصفانه مصنوعات، قیمت تفکیک‌شده و سفارش قابل پیگیری.»

## ضددامنه اولیه
- معاملات وزنی طلای آب‌شده، کیف پول طلایی و نگهداری دارایی مشتری؛ تا تعیین مجوز مستقل.
- فروش اقساطی/اعتباردهی بدون شریک و ساختار قانونی.
- نرم‌افزارهای سنگین AR یا هوش مصنوعی قبل از اثبات بازار.
- انبارداری مرکزی تمام فروشندگان در روز اول.

جزئیات آزمون را در [فرضیه‌ها و مصاحبه](./فرضیه-ها-و-مصاحبه.md) ثبت کنید.
