# Brand Book — پیش‌نویس اولیه Gold-shop

> این سند دستور طراحی **پیشنهادی** است؛ نام نهایی برند، لوگو، دامنه و هویت حقوقی تصویب نشده‌اند. «Gold-shop» نام فعلی مخزن است، نه نام تجاری نهایی.

## هسته برند
- ماموریت: خرید مصنوعات طلا و جواهر را شفاف‌تر، قابل مقایسه‌تر و قابل اعتمادتر کنیم.
- وعده محصول: انتخاب از فروشندگان احرازشده با اطلاعات روشن درباره محصول و اجزای قیمت.
- مخاطب: خریداران هدیه، علاقمندان زیورآلات و گالری‌های معتبر.
- ویژگی شخصیتی: حرفه‌ای، دقیق، مدرن، مطمئن؛ بدون اغراق تجملاتی.
- ارزش‌ها: اصالت، شفافیت، انصاف در نمایش اطلاعات، پاسخگویی.
- جایگاه پیشنهادی: بازارگاه انتخاب آگاهانه طلا و جواهر.

## شعارهای پیشنهادی (آزمایشی)
- «طلا را آگاهانه انتخاب کن»
- «انتخاب بیشتر، قیمت شفاف‌تر»
- «از گالری‌های معتبر، با اطمینان انتخاب کن»

از ادعای تضمین سود، «ارزان‌ترین در ایران»، ضمانت بدون پشتوانه و بازده سرمایه‌گذاری پرهیز شود.

## پالت رنگ پیشنهادی
| نقش | رنگ | HEX |
|---|---|---|
| Primary / سرمه‌ای عمیق | Deep Navy | #142536 |
| Accent / طلایی مات | Matte Gold | #B99A63 |
| Background / عاجی | Ivory | #F6F2EA |
| Text / ذغالی | Charcoal | #292929 |

- طلایی فقط برای تأکید؛ صفحات پرداخت و فاکتور باید خوانا و دارای کنتراست کافی باشند.
- موفقیت/خطا فقط با رنگ نشان داده نشوند؛ متن و آیکون نیز لازم است.

## تایپوگرافی
- فارسی UI: Vazirmatn یا Estedad (بر اساس تست خوانایی، لایسنس و عملکرد).
- لوگوتایپ: طراحی اختصاصی؛ ابتدا نام نهایی ثبت/بررسی شود.
- استفاده از فونت وب با منابع و مجوز معتبر و رعایت دسترس‌پذیری.

## لحن نوشتار
- روشن و قابل سنجش: «وزن: ۱٫۵ گرم»، «اجرت»، «فروشنده تأییدشده».
- محترمانه و مطمئن، نه هیجانی یا بیش‌ازحد صمیمی.
- تمام ادعاهای اصالت، مجوز، بیمه و سیاست بازگشت باید واقعاً قابل اثبات باشند.

## نظام تصویری
- عکس حرفه‌ای با زمینه روشن و نمایش مقیاس واقعی.
- نمای نزدیک از جزئیات قفل، سنگ، بافت، قطر و وزن.
- پرهیز از رندر گمراه‌کننده و تغییر رنگ غیرواقعی طلا.
- اگر عکس تولیدشده/شبیه‌سازی‌شده است، شفاف برچسب‌گذاری شود.
