# تحلیل رقبا | Gold-shop

**آخرین تحقیق:** ۲۰۲۶-۱۱-۲۳ (۲ آذر ۱۴۰۵)  
**دامنه:** ایران، فروش آنلاین مصنوعات طلا و جواهر؛ خریدوفروش طلای آب‌شده صرفاً رقیب غیرمستقیم

## مهم‌ترین یافته
- **طلاباش:** فروشنده‌شو + پنل فروشنده، مدل اشتراک و خدمات عملیاتی قابل مشاهده؛ مهم‌ترین benchmark مدل چندفروشنده.
- **دیجی زرگر:** کاتالوگ و فیلترهای تخصصی وزن/قیمت/وضعیت آماده‌تحویل + خدمات خاص.
- **زیواز:** تأمین‌کنندگان نام‌برده‌شده در یک صفحه قدیمی و UI مقایسه محصول؛ وضعیت کنونی پنل چندفروشنده نیازمند تأیید.
- **جواهری جواد و ساعتچی:** الگوهای برجسته عمق کاتالوگ و ابزار جست‌وجو/راهنمای قیمت.
- **پرسته، ماوی، تاج و روبی:** الگوهای برندینگ، کالکشن، خدمات مشتری و خرید فیزیکی.
- **میلی/طلاسی/گلدیکا/ملی‌گلد/طلاین/داریک:** الگوی اعتماد و تجربه مالی؛ **نه** رقیب هم‌مدل با بازارگاه مصنوعات.

## روش و محدودیت
رتبه‌ها «تناسب راهبردی و اولویت رصد برای Gold-shop» هستند، **نه** رتبه فروش، امنیت، مجوز، کیفیت یا سهم بازار. ارزیابی کیفی بر اساس مدل فعالیت، تنوع کاتالوگ، قیمت/فیلتر، خدمات مشتری و امکانات فروشنده است. سایت‌های قابل دسترسی مستقیماً بررسی شده‌اند، موارد مسدود یا غیردسترس از منابع ثانویه شناسایی شده‌اند. هیچ خرید واقعی، لاگین به پنل فروشنده یا تست تحویل انجام نشده است.

همه اطلاعات متغیر (قیمت اشتراک، شرایط تسویه، امکانات، مجوز) باید با تاریخ و لینک شاهد در بازبینی آینده ثبت شوند. هیچ سایت یا فروشنده‌ای به دلیل حضور در این تحقیق «معتبر»، «امن برای پرداخت» یا «دارای مجوز کافی» تأیید نمی‌شود.

## داده‌های گمشده
GMV/تعداد سفارش/سهم بازار/تعداد فروشندگان فعال، کمیسیون محرمانه، نرخ بازگشت، کیفیت تحویل و تراکنش، و جزئیات زیرساخت رقبا بدون شواهد کافی **نامشخص** هستند. از تخمین قطعی آنها خودداری شود.
